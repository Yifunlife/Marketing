## 自动执行

1. 阅读受支持的 `@oai/sky` macOS 操作说明，在 Node REPL 中取得 `sky` 客户端。所有 Safari 控制均使用此客户端；不能用 shell、AppleScript 或浏览器配置目录替代。
2. 在 Node REPL 导入项目 `scripts/douyin-safari.mjs`，运行 `collectFactoryExports(sky)`。函数新开官方标签页，核对名称和抖音号，选择两份近30天逐日报表并导出账号、粉丝、作品三个文件。函数返回文件绝对路径。不是工厂号时立即停止，不切换到其他人的账号采集。
3. 项目 Node 运行 `scripts/import-douyin.mjs --account factory --identity shanghaiyiwan --account-report <account> --fans-report <fans> --works-report <works> --apply`。使用已有 Cloudflare CLI 登录；代理按项目环境设置。文件必须是刚导出的官方文件。原件入R2，结构化指标入D1，同一摘要不会冒充新采集。
4. 运行 `scripts/douyin-rankings.mjs --account factory --output <临时JSON>`，读取需要补封面的榜单条目。没有缺图则跳过。需要补图时，在同一个已核实的官方内容管理标签页，用 `saveFactoryWorkCovers(sky, items)` 分批保存，每批最多10条。它按完整标题（忽略空白格式）与发布时间核实，再用 Safari 原生保存网页归档。不能把旧归档当本次采集。
5. 用 `scripts/extract-douyin-covers.py --works <临时JSON> --output <临时目录> <本次归档...>` 提取实际图片。Safari 的单页应用可能保留首页文档URL；解析器仍须核实官方域名、作品卡片、标题、发布时间和真实图片字节。用步骤3的同一批新报表，加 `--covers <covers.json> --apply` 保存封面关联。新报表不会清空已保存封面。
