# 抖音账号详情与采集验收

每个账号独立核实身份、保存采集结果并匹配广告账户。扫码后的检查自动触发，页面需保持打开；验证码由用户在官方窗口完成。当前扫码入口仅支持乐园号，不能用它采集其他账号。

| 区域 | 所需数据 | 来源及当前状态 |
| --- | --- | --- |
| 增长 | 总粉丝 | 乐园号网页读取时点快照；其他账号尚未核实 |
| 增长 | 本月、昨日净增粉丝 | 逐日新增关注减取消关注；待核实报表，不用近30天代替本月 |
| 产出 | 本月、昨日发布数 | 按作品发布时间或官方逐日报表；待接通 |
| 内容 | 播放、曝光、赞评藏转、主页访客 | 待核实后台支持项与导出，不能默认当作纯自然流量 |
| 作品 | ID、标题、发布时间、播放及互动 | 待取得明细报表；完播率、时长依平台实际提供 |
| 广告 | 昨日、本月、年度费用与月度历史 | 已匹配账户读取官方广告API；失败保留旧值 |
| CRM | 有效客户、成交金额、有效客户成本、投入产出比 | 仅按核实的平台+账号来源关联CRM；未接归因前不计算 |

比较：总粉丝较上月末；月度流量指标较上月同期；昨日较前日。两个期间必须同口径且完整覆盖；基数为零不用除零百分比。

未取得保持未知；后台确定没有该指标时标为不支持。保存原报表至R2，结构化数据至D1；保存账号ID、指标定义、区间、读取时间、来源文件。各账号不得混用，客户不得用点击或私信次数替代。

上线详情结构不代表采集已全部完成。目前抖音采集程序只写入乐园号总粉丝，逐日报表与作品明细仍需在真实登录页面验证和接入。
