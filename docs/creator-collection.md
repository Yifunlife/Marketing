# 乐园号创作后台定时采集

目标：小红书账号 49314445652，显示名“上海亦玩游乐设备集团”，负责人李昕。其他账号绝不能覆盖本账号。

这是本机浏览器采集，非小红书官方 API、非 Cloudflare 独立抓取。每日上海时间08:00执行，依赖本机在线、应用运行及 Safari 创作后台已登录。遇登录过期、验证码、账号不匹配、工具不可用时停止，提醒用户；保留云端上次成功数据，不填零、不改账号权限，不取出 Cookie 或密码。

## 每次执行

1. 用 CUA 查看 Safari 已登录的 https://creator.xiaohongshu.com/new/home 。核实显示名和小红书账号49314445652。账号不符则停止并请用户登录乐园号，不自动退出其他账号。
2. 打开 https://creator.xiaohongshu.com/statistics/fans-data ，读取“总粉丝数”精确值，绝不使用首页“1万”缩写。该页总粉丝可能与首页不同，保存粉丝页值及来源，不自行修正。不要采集活跃粉丝个人资料。
3. 打开 https://creator.xiaohongshu.com/statistics/account/v2 。页面下面“笔记数据”有观看数据、互动数据、涨粉数据、发布数据四个标签。选择“近30日”；每切换标签均核实统计日期。每个标签点击“导出数据”。它导出真实逐日报表（xlsx），不要读取或逆向网页内部接口。
4. 导出之前记录下载开始时间。Safari 下载位置目前为 /Users/markfang/Downloads。用文件修改时间识别本次新下载的四份文件，不拿旧同名文件充数。Safari 可能给文件加序号。将本次文件复制到项目下 asset-staging/creator-runs/<上海日期>/，统一命名近30日观看数据.xlsx、近30日互动数据.xlsx、近30日涨粉数据.xlsx、近30日发布数据.xlsx。保留原下载文件。目录已被git忽略。
5. 使用 /usr/bin/python3 运行 scripts/import-creator.py --account-id 49314445652 --account-name 上海亦玩游乐设备集团 --fans <粉丝页实际值> --directory <本次目录绝对路径> --as-of <上海当天YYYY-MM-DD>，先不加--apply验证。脚本要求最新30个完整日、四表日期一致、净增=新增-取消关注、发布=视频+图文。数据未更新到昨日时当次不导入、提醒延迟；不伪造缺失日期。
6. 验证成功后同样参数加--apply。脚本使用已登录Wrangler将xlsx原件存私有R2，将精简逐日指标及粉丝值写D1。CLI认证失效时请用户登录，不展示令牌；不要创建临时网站管理员会话。源代码不含数据和凭证。
7. 通过 CUA 在 https://yifun-marketing.yifunlife.workers.dev/ 打开小红书乐园号，核对采集时间、昨日发布、昨日净增和月度数据。若看板登录失效，请用户登录，不使用非公开途径读取浏览器会话。
8. 成功时安静完成。仅在首次成功、采集失败、数据延迟、登录失效或用户需要操作时通知；同一阻碍未变化不要重复提醒。

## 数据口径

- 创作后台内容报表是否排除投放流量尚未确认，显示为“账号内容表现”，不能标为纯自然流量。
- 每日净增使用涨粉报表逐日净涨粉，不能用两次实时总粉丝相减替代。
- 月度数据只汇总当月1日至昨日完整覆盖的日期。缺日返回未知，不能把近30日直接当本月。
- 上月同期缺完整覆盖不显示百分比；后台原有“环比”多为滚动窗口对比，不当作自然月环比。
- 聚光广告仍由 Cloudflare 的10:30任务同步。本任务不修改广告或预算。

## 运行与验证

数据库迁移：migrations/0002_creator_data.sql。
逐日数据：creator_daily，以账号+日期去重并回补；账号实时粉丝与采集时间：creator_accounts。
R2原件：creator/<账号>/<采集日期>/<类别>-<内容摘要>.xlsx。
缺失、过时或不一致报表导致导入失败，旧数据保留，界面保留原采集时间。
